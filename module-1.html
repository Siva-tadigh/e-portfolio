COMP7101 · Semester 1, Year 1

Machine Learning Foundations

A core MSc module covering supervised and unsupervised learning, assessed through a group coursework project and an individual written report.

Learning outcomes

as set by the module
  1. Select and justify an appropriate machine learning approach for a given problem and dataset.
  2. Implement, train, and evaluate supervised and unsupervised models using standard tooling.
  3. Critically appraise model performance, including bias, overfitting, and generalisation.

Artefacts

what you produced, and the feedback it received

Customer churn classifier

Group coursework: a gradient-boosted classifier predicting subscription churn from a provided dataset, with an accompanying model card. View on GitHub

Feedback — Module convenor Strong feature engineering and a well-justified model choice; the evaluation section needed a clearer discussion of class imbalance.

Individual report: clustering comparison

A written comparison of k-means and hierarchical clustering on an unlabelled dataset, including a discussion of when each is appropriate.

Feedback — Module convenor Good technical depth; asked for more critical engagement with the limitations of the chosen evaluation metrics.

Reflection

what did I actually learn, and how?

Coming into this module with a software engineering background rather than a statistics one, the biggest adjustment was learning to treat model evaluation as an argument to be made, not a single accuracy number to report. Building the churn classifier as a group forced me to defend modelling choices out loud, which surfaced assumptions I hadn't noticed I was making about the data.

The convenor's feedback on class imbalance was the clearest lesson: a high accuracy score had hidden a model that was barely better than predicting the majority class. Going forward I want to check class balance and baseline performance before trusting any headline metric.
